## 📂 Featured Projects

### 🎓 [AI Career Development Platform](https://github.com/sriram162007/AI-Powered-Career-Development-Platform)
A full-stack career preparation application designed to help students evaluate resume readiness and practice technical skills.
- **Resume Analysis & ATS Scoring:** Parses uploaded resumes (`.pdf`, `.docx`) and evaluates keyword alignment and formatting for ATS filters.
- **AI Feedback & Mock Interviews:** Connects with the Google Gemini API to generate tailored revision suggestions and technical interview questions.
- **Tech Stack:** React 19, TypeScript, Node.js, Express, Firebase Auth & Firestore, Tailwind CSS

### 🎫 [QR Resolution System](https://github.com/sriram162007/Qr-resolution)
A location-based grievance registration and incident management tool.
- **Friction-Free Incident Reporting:** Users scan location-tagged QR codes to log complaints without requiring account registration.
- **Ticket Lifecycle & Automated Alerts:** Real-time tracking dashboard for administrators and automated status updates dispatched via Twilio WhatsApp API.
- **Tech Stack:** React, TypeScript, Firebase, Twilio API, Vite

### 💬 WhatsApp AI Expense Tracker
An automated personal finance bot built to log expenses through chat.
- **Multimodal Message Processing:** Captures expense entries through voice notes, text messages, and receipt photos using OCR.
- **Automated Workflow:** Uses **n8n** and **Twilio WhatsApp API** to parse entries with Gemini AI and sync categorized expenses into Google Sheets.
- **Tech Stack:** n8n, Twilio WhatsApp API, Google Gemini AI, Google Sheets
